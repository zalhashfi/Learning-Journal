# Quiz Modul 2: Pendahuluan Web Programming

**Soal 1**
**Pertanyaan:** Apa peran dari CSS pada sebuah website?
**Jawaban Benar:** Berperan untuk mempercantik tampilan pada sebuah website agar terlihat menarik.
*Penjelasan:* CSS bertindak layaknya "kulit dan bulu" dalam anatomi website yang berfungsi memberikan *styling*, warna, dan tata letak agar halaman web terlihat lebih menarik. (Sedangkan HTML adalah kerangkanya, dan JavaScript yang membuatnya dinamis/interaktif).

**Soal 2**
**Pertanyaan:** Berikut ini yang BUKAN merupakan fungsi yang tepat dari Developer Tools pada browser adalah ...
**Jawaban Benar:** Tools yang digunakan untuk melakukan request ke sebuah server.
*Penjelasan:* Melakukan *request* ke server adalah fungsi utama dari *browser* itu sendiri (sebagai *client*). Developer Tools (DevTools) secara spesifik adalah seperangkat alat tambahan yang digunakan oleh pengembang web untuk mencari bug, memperbaiki kode, hingga mensimulasikan tampilan responsif di layar perangkat seluler.

**Soal 3**
**Pertanyaan:** Mengapa tidak disarankan menuliskan sebuah kode program menggunakan Microsoft Word?
**Jawaban Benar:** Kode program harus dituliskan dalam bentuk plain text.
*Penjelasan:* Microsoft Word memproses teks dalam format *Rich Text* (memiliki meta-format tersembunyi seperti jenis font, ukuran, tebal/miring, dsb). Sedangkan kode program (seperti HTML/CSS) harus diketik murni tanpa *formatting* (*Plain Text*) agar bisa dibaca dan dieksekusi secara tepat oleh komputer dan browser.

**Soal 4**
**Pertanyaan:** Apa kelebihan website dibanding aplikasi native?
**Jawaban Benar:** Semua di atas
*Penjelasan:* Salah satu keunggulan utama website adalah *cross-platform*. Website dapat dengan mudah diakses dari berbagai jenis perangkat yang ada di pilihan jawaban (desktop, smartphone, smart-tv, hingga smart device lainnya) asalkan perangkat tersebut memiliki *browser* dan koneksi internet, tanpa perlu mengunduh aplikasi *native* secara khusus.

**Soal 5**
**Pertanyaan:** Apa fungsi dari HTTP Server?
**Jawaban Benar:** Sebuah software yang dapat menerima transaksi dari HyperText Transfer Protocol dalam suatu website.
*Penjelasan:* Berdasarkan glosarium modul, HTTP Server adalah *software* atau program pada sisi server yang dirancang khusus untuk melayani, menerima, dan merespons siklus transaksi (*request/response*) yang dikirimkan oleh browser (*client*) melalui protokol HTTP.
