# Quiz Modul 3: Pengenalan HTML

**Soal 1**
**Pertanyaan:** Teks yang menampilkan konten dalam bentuk paragraf sebaiknya disimpan pada sebuah elemen?
**Jawaban Benar:** `<p>`
*Penjelasan:* Huruf "p" pada elemen `<p>` merupakan singkatan dari *paragraph*. Elemen ini adalah standar yang digunakan di HTML untuk membungkus blok teks berupa paragraf. Sedangkan `<h1>`, `<h2>`, dan `<h3>` digunakan untuk *heading* atau judul utama.

**Soal 2**
**Pertanyaan:** Elemen yang berfungsi untuk memberitahukan browser bahwa berkas tersebut merupakan sebuah berkas HTML adalah fungsi dari elemen?
**Jawaban Benar:** `Elemen <html>`
*Penjelasan:* Berdasarkan hierarki anatomi HTML (DOM Tree), elemen `<html>` bertindak sebagai akar (*root*) dari sebuah halaman web. Ia berfungsi membungkus seluruh elemen lainnya dan memberitahu *browser* bahwa dokumen tersebut adalah dokumen HTML.

**Soal 3**
**Pertanyaan:** Apa pengertian dari JavaScript?
**Jawaban Benar:** Bahasa pemrograman yang digunakan untuk membantu website menampilkan informasi secara dinamis.
*Penjelasan:* Dalam anatomi website, HTML berfungsi sebagai struktur (kerangka), CSS berfungsi sebagai pengatur gaya (kulit/tampilan), dan JavaScript adalah bahasa pemrograman logis yang membuat halaman web bisa interaktif dan dinamis.

**Soal 4**
**Pertanyaan:** Apa pengertian dari halaman web?
**Jawaban Benar:** Sebuah halaman yang menampilkan informasi melalui teks atau gambar pada Browser.
*Penjelasan:* Sebuah halaman web (web page) pada dasarnya adalah dokumen yang bisa dibuka menggunakan *browser* dan berfungsi menyajikan informasi secara visual kepada pengguna, baik melalui media teks, gambar, maupun video.

**Soal 5**
**Pertanyaan:** Seperti apakah contoh penulisan commenting yang benar?
**Jawaban Benar:** `<!-- -->`
*Penjelasan:* Fitur komentar (commenting tag) di dalam HTML diawali dengan `<!--` (buka kurung sudut, tanda seru, dan dua setrip) lalu selalu diakhiri dengan `-->` (dua setrip dan tutup kurung sudut). Teks yang diapit oleh tag ini tidak akan dirender oleh *browser*.
