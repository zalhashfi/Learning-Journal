# List

Sama seperti membuat dokumen biasa, dalam HTML kita juga dapat menampilkan konten dalam bentuk daftar struktur (*list*). Terdapat tiga tipe *list* utama pada HTML:

1. **Unordered lists**: Daftar yang ditampilkan tidak memiliki urutan (biasanya menggunakan simbol/bullet).
2. **Ordered lists**: Daftar yang ditampilkan secara terurut (berupa angka atau huruf).
3. **Description lists**: Daftar yang terbuat dari beberapa istilah diikuti dengan deskripsi dari istilah tersebut.

## 1. Unordered List
*Unordered list* merupakan daftar yang tidak mementingkan urutan. Secara standar (*default*), *unordered list* akan menampilkan *bullet* pada tiap *item list*-nya.
- Untuk membuat *unordered list*, kita menggunakan elemen `<ul>` (*Unordered List*).
- Di dalam elemen `<ul>`, setiap poinnya dibungkus dengan elemen `<li>` (*List Item*).

Contoh:
```html
<ul>
  <li>Paragraf atau teks pertama</li>
  <li>Poin kedua</li>
</ul>
```
Kita juga bisa menambahkan elemen `<ul>` lagi di dalam sebuah `<li>` untuk membuat *nested list* (list bersarang).

## 2. Ordered List
*Ordered list* digunakan untuk membuat *list* yang mementingkan urutan, seperti langkah-langkah instruksi. 
- Untuk membuat *ordered list*, kita menggunakan elemen `<ol>` (*Ordered List*).
- Poin-poin di dalamnya juga dibungkus menggunakan elemen `<li>`.

Contoh:
```html
<ol>
  <li>Langkah pertama</li>
  <li>Langkah kedua</li>
</ol>
```

Pada *ordered list*, tipe urutan dapat kita atur dengan beberapa atribut:
- **Atribut `type`**: Mengubah format angka. Nilai yang bisa dipakai antara lain:
  - `"1"` : Angka default (1, 2, 3...)
  - `"a"` : Huruf kecil (a, b, c...)
  - `"A"` : Huruf besar (A, B, C...)
  - `"i"` : Angka Romawi kecil (i, ii, iii...)
  - `"I"` : Angka Romawi besar (I, II, III...)
- **Atribut `start`**: Menentukan angka/huruf awal urutan dimulai (misalnya `<ol start="7">` untuk mulai dari angka 7).
- **Atribut `reversed`**: Membuat urutan angka diurutkan secara terbalik (dari besar ke kecil). Atribut ini berdiri sendiri dan tidak memerlukan nilai (*boolean attribute*).
