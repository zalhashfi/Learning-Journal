# 🌐 Kelas: Belajar Dasar Pemrograman Web

Folder ini berisi rangkuman pembelajaran, latihan, dan persiapan kuis untuk kelas fundamental **Belajar Dasar Pemrograman Web** (Bagian dari alur Progressive Full-Stack Developer DBS Foundation).

Kelas ini bertujuan untuk membangun pondasi paling mendasar tentang bagaimana sebuah website terstruktur sebelum dipadukan dengan *styling* tingkat lanjut ataupun pemrograman *logic*.

## 🗂️ Silabus Modul

1. **[1. Persiapan Belajar](./1.%20Persiapan%20Belajar/)**
   - Membahas tentang mekanisme belajar, forum diskusi, glosarium, dan _requirement tools_ (Editor, Browser).
2. **[2. Pendahuluan](./2.%20Pendahuluan/)**
   - Membahas konsep dasar web, perbedaan web dan *native app*, server HTTP, peran HTML, CSS, JavaScript, serta DevTools. Terdapat **Quiz** di dalamnya.
3. **[3. Pengenalan HTML](./3.%20Pengenalan%20HTML/)**
   - Membahas anatomi elemen HTML, hirarki DOM, atribut (class, id, dll), hingga praktik membuat dokumen menggunakan `<!DOCTYPE html>`.

## 📌 Cara Menggunakan Catatan
Semua file di dalamnya disimpan dalam bentuk `.md` (Markdown). Sangat disarankan membukanya lewat **Obsidian** agar format teks, tabel, maupun *tag* dan kuis dapat terlihat rapi dan saling terkoneksi.
