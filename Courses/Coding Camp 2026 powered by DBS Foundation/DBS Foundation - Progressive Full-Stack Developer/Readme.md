# 💻 DBS Foundation - Progressive Full-Stack Developer

Ini adalah folder pembelajaran untuk jalur (learning path) **Progressive Full-Stack Developer** dari beasiswa **Coding Camp 2026 powered by DBS Foundation**.

Jalur ini dirancang untuk membekali pengetahuan dari sisi Front-End (tampilan aplikasi) maupun Back-End (sistem di balik layar) agar menjadi seorang *developer* utuh.

## 🗂️ Daftar Kelas / Materi

Jalur ini memiliki beberapa kelas utama yang harus diselesaikan:

1. **[Belajar Dasar Pemrograman Web](./Belajar%20Dasar%20Pemrograman%20Web/)**
   - Pengenalan mengenai HTML dan struktur web dasar.
2. **Belajar Dasar Pemrograman Javascript**
   - Bahasa wajib agar sebuah halaman web dapat interaktif dan dinamis.
3. **Belajar Membuat Front-End Web untuk Pemula**
   - Pemahaman lanjutan terkait CSS, DOM Manipulation, dan web storage (penyimpanan sisi peramban).

*Masing-masing kelas berisikan modul, kuis, rangkuman (`Summary.md`), serta proyek akhirnya tersendiri.*
