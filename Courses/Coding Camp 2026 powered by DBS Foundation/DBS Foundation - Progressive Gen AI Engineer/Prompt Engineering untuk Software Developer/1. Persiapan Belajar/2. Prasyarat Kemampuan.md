Materi pada kelas ini dirancang ramah untuk software developer dari segala bidang dan tingkatan. Anda sebagai software developer, diharapkan memiliki pengetahuan dasar mengenai penggunaan komputer dan logika pemrograman. Berikut adalah detail prasyarat kemampuan yang harus Anda miliki pada kelas ini.

### Kemampuan Penggunaan Komputer

- Pengetahuan dasar komputer
- Kemampuan navigasi website
- Kemampuan memecahkan masalah
- Kemampuan belajar mandiri

### Logika Dasar Pemrograman

- Logika pemrograman
- Algoritma pemrograman
- Gerbang logika

### Dasar Pemrograman untuk Menjadi Pengembang Software

- Memahami kebutuhan aplikasi
- Mengerti konsep dasar pemrograman
- Merancang aplikasi perangkat lunak
- Dokumentasi pengembangan aplikasi perangkat lunak
