# Summary: Persiapan Belajar

Dokumen ini berisi rangkuman komprehensif dari 7 materi pada modul **Persiapan Belajar** (Kelas Prompt Engineering untuk Software Developer).

## [1. Pengenalan Kelas.md](file:///C:/Documents/Learning-Journal/Courses/Coding%20Camp%202026%20powered%20by%20DBS%20Foundation/DBS%20Foundation%20-%20Progressive%20Gen%20AI%20Engineer/Prompt%20Engineering%20untuk%20Software%20Developer/1.%20Persiapan%20Belajar/1.%20Pengenalan%20Kelas.md)

- **Dampak Generative AI pada Developer:** Berdasarkan riset McKinsey & Company (2023), Generative AI mampu meningkatkan efisiensi software developer hingga 2x lipat (terutama untuk coding, refactoring, dan dokumentasi) serta meningkatkan penyelesaian tugas berkompleksitas tinggi sebesar 25-30%.
- **Pentingnya Prompt Engineering:** Peningkatan produktivitas memerlukan perancangan prompt yang efektif (*best practices*) agar AI menghasilkan respons yang relevan dan akurat.
- **Struktur Modul Pembelajaran:**
  - **Modul 1:** Pengenalan Prompt Engineering & cara kerja model AI.
  - **Modul 2:** Berbagai Pola (*Prompt Engineering Patterns*) untuk respons yang adaptif dan konsisten.
  - **Modul 3:** Penerapan Prompt Engineering dalam berbagai aktivitas *Software Development*.
  - **Modul 4:** Limitasi dan Etika Penggunaan Prompt Engineering untuk AI.

## [2. Prasyarat Kemampuan.md](file:///C:/Documents/Learning-Journal/Courses/Coding%20Camp%202026%20powered%20by%20DBS%20Foundation/DBS%20Foundation%20-%20Progressive%20Gen%20AI%20Engineer/Prompt%20Engineering%20untuk%20Software%20Developer/1.%20Persiapan%20Belajar/2.%20Prasyarat%20Kemampuan.md)

- **Penggunaan Komputer:** Navigasi web, pemecahan masalah (*problem solving*), dan belajar mandiri.
- **Logika Pemrograman:** Logika dasar, algoritma pemrograman, dan gerbang logika.
- **Dasar Software Development:** Pemahaman kebutuhan aplikasi, konsep dasar pemrograman, perancangan aplikasi, dan pendokumentasian.
- **Rekomendasi:** Disarankan (opsional) mengikuti kelas *Programming Logic 101* dan *Dasar Pemrograman untuk Menjadi Pengembang Software* jika ingin memperkuat pemahaman dasar.

## [3. Prasyarat Tools.md](file:///C:/Documents/Learning-Journal/Courses/Coding%20Camp%202026%20powered%20by%20DBS%20Foundation/DBS%20Foundation%20-%20Progressive%20Gen%20AI%20Engineer/Prompt%20Engineering%20untuk%20Software%20Developer/1.%20Persiapan%20Belajar/3.%20Prasyarat%20Tools.md)

- **Komputer/Laptop & Internet:** Sistem operasi Windows, Linux, atau macOS dengan koneksi internet (Minimal RAM 1 GB / Rekomendasi RAM 2 GB, layar 1366x768 / Rekomendasi Full HD).
- **Web Browser:** Google Chrome, Firefox, Edge, atau browser modern lainnya.
- **Alat AI:** Bebas menggunakan ChatGPT, Gemini, Claude, atau alat AI generatif lainnya (fokus kelas adalah teknik merancang prompt yang efektif, bukan membandingkan produk AI).
- **Bahasa Pemrograman:** Contoh dalam modul akan menggunakan **Python**, tetapi peserta bebas menerapkan prompt dengan bahasa pemrograman apapun sesuai kebutuhan.

## [4. Mekanisme Belajar.md](file:///C:/Documents/Learning-Journal/Courses/Coding%20Camp%202026%20powered%20by%20DBS%20Foundation/DBS%20Foundation%20-%20Progressive%20Gen%20AI%20Engineer/Prompt%20Engineering%20untuk%20Software%20Developer/1.%20Persiapan%20Belajar/4.%20Mekanisme%20Belajar.md)

- **Materi Berbasis Teks:** Format bacaan elektronik dinilai paling efektif untuk penguasaan materi pemrograman dan latihan praktik.
- **Forum Diskusi:** Tempat bertanya dan berdiskusi teknis seputar materi dengan instruktur (Curriculum Developer, Code Reviewer) dan peserta lain.
- **Layanan Administrasi:** Pertanyaan seputar situs/akun dilakukan via *live chat* kanan bawah (bukan di forum diskusi).
- **Evaluasi:** Menguji pemahaman melalui Kuis dan Ujian Akhir Kelas.

## [5. Forum Diskusi.md](file:///C:/Documents/Learning-Journal/Courses/Coding%20Camp%202026%20powered%20by%20DBS%20Foundation/DBS%20Foundation%20-%20Progressive%20Gen%20AI%20Engineer/Prompt%20Engineering%20untuk%20Software%20Developer/1.%20Persiapan%20Belajar/5.%20Forum%20Diskusi.md)

- **Etika & Akses:** Wajib bersikap sopan dan saling menghormati. Akses forum berlaku selama masa aktif atau selamanya jika telah lulus kelas.
- **Pencarian Diskusi:** Gunakan fitur pencarian (Cari Judul, Berdasarkan Modul, Keyword Populer) sebelum membuat postingan baru.
- **Fitur Kunci:**
  - *Upvote / Downvote:* Menjaga kualitas dan relevansi tanggapan.
  - *Approved Answer (Jawaban Terpilih):* Menandai solusi terbaik untuk mempermudah siswa lain.
- **Networking:** Thread perkenalan khusus untuk saling membangun jaringan sesama developer.

## [6. Glosarium.md](file:///C:/Documents/Learning-Journal/Courses/Coding%20Camp%202026%20powered%20by%20DBS%20Foundation/DBS%20Foundation%20-%20Progressive%20Gen%20AI%20Engineer/Prompt%20Engineering%20untuk%20Software%20Developer/1.%20Persiapan%20Belajar/6.%20Glosarium.md)

Kamus istilah penting yang dipakai dalam pengembangan perangkat lunak & Prompt Engineering:
- **Best Practice:** Pendekatan/teknik pengembangan yang terbukti efektif dan efisien.
- **Data Model:** Representasi struktur data untuk mengelola logika dan hubungan antardata.
- **Deprecated:** Fitur/kode yang sudah tidak disarankan karena akan dihapus di versi mendatang.
- **Dummy:** Data sampel/palsu sementara untuk kebutuhan pengujian.
- **Distribusi Probabilitas:** Representasi matematis untuk menghitung kemungkinan keluaran teks berikutnya pada AI.
- **Halusinasi:** Respons AI yang tidak sesuai fakta kebenaran.
- **Onboarding:** Proses penyesuaian developer baru ke dalam tim, *codebase*, dan alur kerja proyek.
