# 🤖 DBS Foundation - Progressive Gen AI Engineer

Ini adalah folder pembelajaran untuk jalur (learning path) **Progressive Gen AI Engineer** dari beasiswa **Coding Camp 2026 powered by DBS Foundation**.

Jalur ini ditujukan untuk mendalami teknologi *Artificial Intelligence* masa kini, khususnya dalam memanfaatkan dan merekayasa AI Generatif.

## 🗂️ Daftar Modul Pembelajaran

1. **Memulai Pemrograman dengan Python**
   - Belajar sintaks dasar Python, tipe data, fungsi, hingga konsep OOP yang merupakan pondasi utama pengembangan AI.
2. **Belajar Dasar AI**
   - Pengenalan mengenai apa itu kecerdasan buatan dan perkembangannya.
3. **Belajar Machine Learning untuk Pemula**
   - Mempelajari cara mesin dapat dilatih untuk mengenali pola data.
4. **Prompt Engineering untuk Software Developer**
   - Teknik menyusun *prompt* secara terstruktur untuk mengoptimalkan penggunaan LLM (Large Language Models).

*Silakan jelajahi setiap folder untuk membaca catatan, kode latihan, dan rangkuman masing-masing kelas.*
