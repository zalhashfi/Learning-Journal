### Apa yang Akan Anda Pelajari?

Kelas ini terbagi menjadi enam (6) modul yang akan membawa Anda melalui seluruh siklus hidup proyek data science di Microsoft Fabric:

- **Modul 1: Mengupas Tuntas Analitik End-to-End dengan Microsoft Fabric  
    **Di awal perjalanan ini, Anda akan mampu mengidentifikasi berbagai kemampuan yang ditawarkan oleh Microsoft Fabric dan menerapkannya secara strategis untuk memenuhi kebutuhan analitik di perusahaan Anda. Anda akan memahami bagaimana platform ini menyatukan semua layanan analitik dalam satu lingkungan terpadu.
- **Modul 2: Menyelami Dunia Data Science dengan Microsoft Fabric  
    **Modul ini mengajarkan Anda untuk memahami alur kerja dalam proses data science secara keseluruhan. Anda akan belajar melatih model menggunakan notebook di Microsoft Fabric serta melacak metrik pelatihan model dengan MLflow dan experiments.
- **Modul 3: Menjelajahi Data untuk Data Science dengan Notebook di Microsoft Fabric  
    **Anda akan menguasai langkah krusial yaitu Exploratory Data Analysis (EDA). Materi ini mencakup cara memuat data ke dalam notebook, memahami konsep missing data dan strategi penanganannya, serta menyajikan data secara visual menggunakan beragam teknik.
- **Modul 4: Preprocessing Data dengan Data Wrangler di Microsoft Fabric  
    **Fase preprocessing data adalah kunci untuk menyiapkan data agar siap untuk modeling. Anda akan mengupas tuntas fitur Data Wrangler, mencoba operasi preprocessing umum, mempelajari strategi menangani missing values, dan menggunakan one-hot encoding untuk mengubah data kategorikal.
- **Modul 5: Melatih dan Melacak Model Machine Learning dengan MLflow di Microsoft Fabric  
    **Modul ini adalah "dapur" untuk meracik model Anda. Anda akan belajar melatih model machine learning menggunakan framework open-source populer, menggunakan notebook di Microsoft Fabric, dan melacak semua metrik penting pelatihan model dengan MLflow dan experiments.
- **Modul 6: Menghasilkan Batch Prediction menggunakan Model yang Di-deploy di Microsoft Fabric  
    **Setelah model selesai, saatnya memanfaatkannya. Anda akan mempelajari cara menyimpan model, menyiapkan dataset baru sebagai "bahan" untuk prediksi, menggunakan model untuk menghasilkan prediksi, dan menyimpan hasil prediksi ke dalam Delta table untuk diolah lebih lanjut.
