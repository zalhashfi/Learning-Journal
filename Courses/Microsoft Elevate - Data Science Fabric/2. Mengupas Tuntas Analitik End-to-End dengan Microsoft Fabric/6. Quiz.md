# Quiz: Mengupas Tuntas Analitik End-to-End dengan Microsoft Fabric
*Modul 2: Belajar Penerapan Data Science dengan Microsoft Fabric*

Berikut adalah daftar soal kuis beserta kunci jawaban dan penjelasannya untuk Modul 2.

---

### Soal 1
**Pertanyaan:**  
Seorang user business intelligence ingin menjelajah dan menemukan dataset terkurasi dengan mudah, serta memastikan hanya data yang sudah dibagikan dapat diakses. Layanan manakah dalam Fabric yang memenuhi kebutuhan ini?

**Pilihan Jawaban:**
- [ ] Workload Data Science
- [ ] Fabric pipeline editor
- [ ] Compute engine pipeline
- [x] **OneLake catalog**

**Jawaban Benar:** `OneLake catalog`

> **Penjelasan:**  
> Terhubung dengan materi [[4. Mengaktifkan dan Menggunakan Microsoft Fabric|OneLake Catalog]].  
> OneLake catalog berfungsi seperti katalog perpustakaan yang memudahkan pengguna menemukan dan mengakses berbagai sumber data di organisasi Anda. Pengguna hanya akan melihat item yang telah dibagikan kepada mereka.

### Soal 2
**Pertanyaan:**  
Apa format penyimpanan default untuk OneLake di Fabric?

**Pilihan Jawaban:**
- [x] **Delta-Parquet**
- [ ] CSV
- [ ] HTML
- [ ] JSON

**Jawaban Benar:** `Delta-Parquet`

> **Penjelasan:**  
> Terhubung dengan materi [[2. Menjelajahi Analitik End-to-End dengan Microsoft Fabric|OneLake]].  
> Untuk data tabular, *analytical engines* di Fabric menulisnya dalam format **Delta-Parquet**, yang memastikan semua *engine* dapat berinteraksi dengan data tersebut secara mulus.

### Soal 3
**Pertanyaan:**  
Bagaimana Microsoft Fabric mendukung skenario data mesh yang efisien di perusahaan berbasis analitik?

**Pilihan Jawaban:**
- [ ] Kolaborasi lintas tim melalui infrastruktur analitik yang independen
- [x] **Kepemilikan data terdesentralisasi dengan tata kelola terpusat**
- [ ] Peningkatan efisiensi pipeline dengan integrasi platform eksternal khusus
- [ ] Optimalisasi kontrol akses melalui isolasi penuh antar unit data

**Jawaban Benar:** `Kepemilikan data terdesentralisasi dengan tata kelola terpusat`

> **Penjelasan:**  
> Terhubung dengan materi [[4. Mengaktifkan dan Menggunakan Microsoft Fabric|Fabric Workloads & Data Mesh]].  
> Fabric mendukung arsitektur *data mesh*, yang memungkinkan kepemilikan data terdesentralisasi (dipegang oleh domain bisnis), tetapi dengan tata kelola terpusat.
