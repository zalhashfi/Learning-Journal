Data adalah fondasi dari setiap proyek **data science**, terutama ketika Anda ingin melatih sebuah model **machine learning** untuk mencapai AI. Secara umum, performa model cenderung meningkat seiring dengan bertambahnya volume _dataset_ pelatihan. Namun, selain kuantitas, kualitas data juga memegang peranan yang sama pentingnya.

Untuk memastikan kualitas dan kuantitas data, Anda dapat memanfaatkan fitur **data ingestion** dan **processing** yang ada di Microsoft Fabric. Anda diberikan fleksibilitas untuk memilih antara pendekatan **low-code** atau **code-first** saat membangun **pipelines** untuk proses _ingestion_, eksplorasi, dan transformasi data.

  

### Meng-_ingest_ Data ke Microsoft Fabric

Untuk mulai bekerja dengan data di Microsoft Fabric, langkah pertama yang perlu Anda lakukan adalah **ingestion**. Sumber data bisa sangat beragam, baik dari sistem lokal (_on-premise_) maupun dari **cloud data sources**. Sebagai contoh, Anda dapat meng-_ingest_ data dari file CSV yang tersimpan di komputer lokal atau di Azure Data Lake Storage (Gen2).

|   |
|---|
|Tip: Pelajari lebih lanjut tentang cara [meng-ingest dan mengorkestrasi data dari berbagai sumber dengan Microsoft Fabric](https://learn.microsoft.com/id-id/training/paths/ingest-data-with-microsoft-fabric/).|

Setelah terhubung ke sumber data, Anda dapat menyimpannya ke dalam _lakehouse_ di Microsoft Fabric. Anda dapat menggunakan _lakehouse_ sebagai lokasi terpusat untuk menyimpan berbagai jenis file, baik yang terstruktur, semi-terstruktur, maupun tidak terstruktur. Selanjutnya, Anda dapat dengan mudah terhubung ke lakehouse untuk mengakses data yang akan dieksplorasi atau ditransformasi.

  

### Mengeksplorasi dan Mentransformasi Data

Sebagai seorang data scientist, Anda mungkin sudah terbiasa menulis dan menjalankan kode di dalam _notebooks_. Microsoft Fabric menawarkan pengalaman _notebook_ yang familier, yang didukung oleh kekuatan [**Spark compute**](https://learn.microsoft.com/en-us/fabric/data-engineering/spark-compute).

**Apache Spark** adalah sebuah _framework_ pemrosesan paralel _open-source_ yang dirancang untuk pemrosesan dan analisis data berskala besar.

**Notebook** secara otomatis terhubung dengan **Spark compute**. Saat Anda menjalankan sebuah cell di _notebook_ untuk pertama kalinya, sebuah sesi Spark baru akan dimulai. Sesi ini akan tetap aktif saat Anda menjalankan cell berikutnya. Untuk menghemat biaya, sesi Spark akan berhenti secara otomatis setelah beberapa waktu tidak aktif, tetapi Anda juga bisa menghentikannya secara manual.

Saat bekerja di dalam _notebook_, Anda memiliki kebebasan untuk memilih bahasa pemrograman yang ingin digunakan. Untuk proyek _data science_, kemungkinan besar Anda akan bekerja dengan PySpark (Python) atau SparkR (R).

### Menyiapkan Data dengan Data Wrangler

Untuk membantu Anda menjelajahi dan mentransformasi data dengan lebih cepat, Microsoft Fabric menyediakan sebuah alat bantu yang mudah digunakan bernama [Data Wrangler](https://learn.microsoft.com/en-us/fabric/data-science/data-wrangler).

Saat menggunakan **Data Wrangler**, Anda akan disajikan ringkasan deskriptif dari data yang sedang Anda olah. Anda dapat melihat ringkasan statistik data untuk membantu menemukan masalah seperti nilai yang hilang (_missing values_) dengan cepat.

Untuk membersihkan data, Anda dapat memilih salah satu dari berbagai operasi pembersihan data (**data cleaning**) bawaan. Ketika Anda memilih sebuah operasi, akan muncul pratinjau hasil beserta kode yang dibuat secara otomatis. Setelah memilih semua operasi yang diperlukan, Anda dapat mengekspor kode tersebut dan mengeksekusinya pada data.
