# 📚 Microsoft Elevate - Data Science Fabric

Ini adalah catatan pembelajaran untuk program **Data Science Fabric** dari **Microsoft Elevate Training Center Skill Sprint**. 

Program ini memfokuskan pada pemahaman tentang cara memanfaatkan Microsoft Fabric untuk kebutuhan *Data Science* dari hulu ke hilir (End-to-End).

## 🗂️ Daftar Modul dan Materi

1. **[Modul 1: Persiapan Belajar](./1.%20Persiapan%20Belajar/)**
   - Materi seputar pendahuluan platform dan instalasi tools.
2. **[Modul 2: Mengupas Tuntas Analitik End-to-End dengan Microsoft Fabric](./2.%20Mengupas%20Tuntas%20Analitik%20End-to-End%20dengan%20Microsoft%20Fabric/)**
   - Integrasi arsitektur analitik data yang menyeluruh menggunakan layanan cloud Fabric.
3. **[Modul 3: Menyelami Dunia Data Science dengan Microsoft Fabric](./3.%20Menyelami%20Dunia%20Data%20Science%20dengan%20Microsoft%20Fabric/)**
   - Mempelajari *Machine Learning* dan *Notebooks* yang ada di dalam Fabric.
