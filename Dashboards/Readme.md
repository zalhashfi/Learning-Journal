# 🧭 Dashboards (Map of Content)

Folder ini berfungsi sebagai **Map of Content (MoC)** atau gerbang utama menuju berbagai topik yang sedang dipelajari dalam repositori jurnal ini.

Daripada mencari satu per satu catatan dari dalam struktur folder `Courses` yang sangat dalam, Anda bisa menjadikan halaman-halaman di sini sebagai *dashboard* utama.

## Konsep Zettelkasten di Folder Ini
Setiap file di dalam folder ini (misal: `AI.md`, `Data Science.md`, `Web Development.md`) berisi kumpulan tautan (links) ke catatan spesifik atau rangkuman yang relevan dengan bidangnya masing-masing.
- Membantu melihat gambaran besar (big picture) dari suatu topik.
- Menghubungkan titik temu materi antar berbagai kelas yang berbeda.

## Daftar Dashboard Aktif
- [[AI]] - Materi kecerdasan buatan, Machine Learning, & Prompt Engineering
- [[Data Science]] - Materi analisis data, big data, dan penerapan Data Science
- [[Web Development]] - Materi seputar pembuatan website, HTML/CSS, dan Javascript
