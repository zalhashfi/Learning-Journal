# Rangkuman: Persiapan Belajar
*Modul 1: Belajar Penerapan Data Science dengan Microsoft Fabric*

Berikut adalah ringkasan dari seluruh materi persiapan sebelum memulai kelas penerapan Data Science dengan Microsoft Fabric.

## 1. [[1. Pengenalan Kelas|Pengenalan Kelas]]
Kelas ini bertujuan untuk membekali peserta dengan keterampilan praktis membangun solusi *machine learning* modern secara *end-to-end* di platform *cloud* menggunakan Microsoft Fabric. 

Materi terbagi menjadi **6 Modul Utama**:
1. **Analitik End-to-End:** Memahami kemampuan analitik terpadu di Microsoft Fabric.
2. **Dunia Data Science:** Memahami alur kerja *data science*, pelatihan model di Notebook, dan *tracking* dengan MLflow.
3. **Eksplorasi Data (EDA):** Menjelajahi data, penanganan *missing value*, dan visualisasi menggunakan Notebook.
4. **Preprocessing Data:** Menyiapkan data untuk modeling menggunakan *Data Wrangler* (termasuk *encoding* & penanganan *missing values*).
5. **Melatih & Melacak Model:** Melatih *machine learning* dan memonitor metrik penting menggunakan *MLflow* dan *experiments*.
6. **Batch Prediction:** Melakukan *deployment* model, memprediksi dataset baru, dan menyimpan hasilnya ke *Delta table*.

## 2. [[2. Rekomendasi Pengetahuan Awal|Pengetahuan & Kemampuan Awal (Prasyarat)]]
Agar proses belajar lebih optimal, sangat disarankan untuk memiliki:
- **Pengetahuan Dasar Pemrograman** & kemampuan membaca dokumentasi teknis berbahasa Inggris.
- **Pemahaman Konsep Cloud** dan kolaborasi data modern.

## 3. [[3. Prasyarat Tools|Prasyarat Tools]]
- **Komputer/Laptop:** OS Windows, Linux, atau macOS. Terhubung dengan internet. (Spesifikasi minimal: RAM 2GB, prosesor Intel Dual Core. Disarankan: RAM 4GB, Resolusi layar Full HD).
- **Web Browser:** Bebas menggunakan Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, dll.

## 4. [[4. Mekanisme Belajar|Mekanisme Belajar]] & [[5. Forum Diskusi|Evaluasi dan Forum Diskusi]]
- **Materi Utama:** Diberikan dalam bentuk teks/bacaan elektronik agar lebih mudah dipraktikkan.
- **Evaluasi:** Pemahaman materi akan diuji melalui Kuis dan Ujian Akhir pada setiap bagiannya.
- Disediakan forum diskusi untuk saling membantu, bertanya, dan berjejaring dengan siswa lain maupun instruktur.
- **Aturan Penting:**
  - Utamakan mencari postingan lama (*search*) sebelum membuat diskusi baru agar tidak terjadi pertanyaan berulang.
  - Bersikap sopan dan saling menghargai.
  - Manfaatkan fitur **Upvote/Downvote** untuk menyeleksi jawaban yang bagus, dan tandai **Approved Answer** jika masalah sudah terselesaikan.
  - Siswa sangat disarankan untuk berkenalan di *thread* Perkenalan Diri.
